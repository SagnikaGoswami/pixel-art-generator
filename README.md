# 🎨 Pixel Art Generator Using Python

A creative Python project exploring pixel art generation through NumPy arrays, RGB colour manipulation, and Matplotlib visualisation.

The project is being developed incrementally, with a focus on understanding image representation, experimenting with pixel-level operations, and applying Python concepts to creative image processing.

## 🛠️ Technologies Used

- **Python** — Core programming language
- **NumPy** — Array creation and pixel manipulation
- **Matplotlib** — Image visualisation
- **Jupyter Notebook** — Development and experimentation

## ✨ Current Progress

The initial development stage focuses on understanding how digital images can be represented and manipulated using NumPy.

Concepts explored so far include:

- Creating two-dimensional and three-dimensional NumPy arrays
- Understanding RGB colour representation
- Modifying individual pixels using array indexing
- Colouring rows, columns, and rectangular regions using NumPy slicing
- Visualising pixel arrays using Matplotlib

## 🚀 Future Development

The project will gradually explore additional functionality, including:

- Generating creative pixel art patterns
- Creating custom pixel artwork
- Converting images into pixel art
- Experimenting with colour palettes and image-processing techniques
- Exporting generated artwork
- Exploring an interactive application interface

Features will be introduced progressively as development continues.

## ▶️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/SagnikaGoswami/pixel-art-generator.git
```

### 2. Install the required libraries

```bash
pip install numpy matplotlib notebook
```

### 3. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open `pixel-art-generator.ipynb` and execute the cells to explore the current experiments.
